Capabilities

Everything a personal AI needs, in one surface.

Not a chat box with extras. Six screens, a real agent kernel behind them, and a gateway that keeps secrets server-side.

Voice that keeps up

Streaming speech in, streaming speech out, with barge-in, turn detection and Hinglish handling. Interrupt mid-sentence — the old generation dies instantly.

Vision on demand

Live camera, stills and screen understanding routed through vision-capable models, with an explicit "demo until connected" state instead of a fake result.

Agent missions

Objectives become task graphs: plan, execute, retry, pause, resume, cancel. Budgets, approvals and checkpoints are enforced in code, not by the model.

Memory vault

Durable, categorised memories with secret redaction. The agent reads only what you keep, and it survives reloads — no cloud account required.

Recon & research

OSINT collectors with correlation, confidence grading and exportable reports, plus deterministic research helpers for cross-checking extracts.

Model router

Task-aware routing across free and paid models with automatic failover when a slug dies. One dead model never becomes your problem.

Accounts & sync

Yours on every device — or on none of them.

METALOID works entirely on this device out of the box. Sign in and the same data follows you: real email/password identity with verification and reset, conversations and memories in Postgres behind row level security, and your provider key encrypted at rest — never in the browser, never in a response.

Identity that is actually identity

Sign up, verify by email, reset a forgotten password, stay signed in across restarts. Sessions refresh automatically; signing out clears this device only.

Row level security, executed

Every user table is owner-only, with private storage paths. 205 security assertions run in CI against real PostgreSQL — anonymous, owner and non-owner, including cross-user probes.

Your key, encrypted

Provider keys are stored server-side with AES-256-GCM under a key from the environment, in a versioned envelope with a rotation path. The UI only ever shows a mask.

Streaming stays fast

The visible path never waits on a database: you send, the gateway streams, the finished turn is persisted after. An interrupted stream is recorded as cancelled, not lost.

Private files

Attachments, generated files and avatars live in private buckets under your own folder, reachable only through short-lived signed links minted after an ownership check.

Delete means delete

Account deletion removes your profile, conversations, messages, memories, attachment records and files, provider settings and keys, tasks and usage — then the identity itself.

Honesty by design

It tells you what it is. Always.

Most assistants fake a green dot. METALOID has four real states, and it will not claim to be online when it is not — no invented sources, no phantom tools, no simulated successes presented as real ones.

ONLINE

A live provider answered. Replies are real model output.

SANDBOX

A local provider is streaming — end to end demos without a key, clearly labelled.

DEGRADED

A key is set but unreachable. It says so instead of failing silently.

LOCAL DEMO

No gateway. A local engine answers, marked as demo in every message.

Architecture

Deterministic code decides. The model reasons.

Permissions, state transitions, schemas, validation, audit and queues are code. Interpretation, planning and language are the model's job — under a constitution it cannot edit.

Keys never reach the browser

Provider credentials live in the gateway's environment. The frontend talks to /api only, so a stolen laptop is not a stolen key.

Failover you can prove

Dead model slugs are quarantined and skipped, rate limits roll to the next candidate, and bad credentials fail fast. Every branch is covered by tests.

Verified outputs

A verification pass scores answers and flags placeholder text, so a "done" mission has evidence behind it.

Local-first data

History, memories and settings live in the browser by default. Point it at a server database when you want sync — not before.
